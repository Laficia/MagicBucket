# 魔法水桶：本地源码恢复版本

当前版本 `1.2.14.6`，基于 [MiSaKaQAQ/MagicBucket v1.2.13](https://github.com/MiSaKaQAQ/MagicBucket/releases/tag/v1.2.13) 发布包恢复。上游 Git 仓库只有安装索引，没有公开 C# 源码；`src/SrankFlag` 是通过 ILSpy 11.2.0.10050 反编译 DLL 后修复编译问题的代码，不是作者原始工程。原作者信息 `hunhuan` 保留在插件清单中。

## 原生样式与手动数据加载

- 原生按钮使用自身标签和悬停/按下动画，不再叠加自绘标签。稳定内容不重复写入文字和尺寸；按钮保持单行，并按实际文字宽度留白。
- 原生选项只在模型选中状态变化时同步，不在鼠标按下与松开之间用旧快照覆盖。版本右键监听复用原生碰撞节点，保留左键多选、右键单选。
- 大区与历史筛选用原生单选；版本、服务器、订阅和设置用原生复选框；进度条使用游戏任务栏纹理组件。条件窗服务器只显示彩色文字。
- 搜索框按窗口宽度缩短，搜索、窗口入口、大区、版本、执行操作、筛选及详情分别排列。条件窗怪名、计时与服名分别占行；自动前往每只 S 独立排列。
- 豆豆柴可自动读取主站；莫古力、猫小胖、陆行鸟**必须手动加载**，只直连公开熊站。其他三个大区不从主站获取实时 S、排点或 relay 状态。
- `/水桶 dc 莫古力` 切区，`/水桶 refresh` 明确手动加载。加载过程中逐步显示结果与进度，切区取消旧请求，缓存保留各区结果。
- 手动刷新在游戏聊天栏提示开始与完成、有效记录数；部分失败、超时、切区取消有独立提示。自动更新只刷新状态栏。
- 三大区手动刷新通过公开熊站 `/api/lastDeathTimers` 批量读取整区。首次需要一次匿名会话 GET 和一次批量 POST，后续复用会话，只发一次 POST。跨区至少间隔 1 分钟，同区至少间隔 5 分钟。遇到缺失项沿用缓存，失败至少等 5 分钟并遵守更长的 `Retry-After`。日志分开记录请求数、请求正文大小和解压后的响应正文大小。
- 公开熊站返回的 `Canceled` 同时支持数字与布尔标记；手动加载可纠正旧撤销记录导致的错误时间，同时保留更新的 Sonar 击杀。新缓存保存纠正后的时间，包括无有效记录的情况。

## 原生传送与落地确认

- 大水晶使用游戏原生传送，按已解锁 ID 调用；跨服仍使用 DailyRoutines 的跨界传送模块。
- 确认目标服务器、地图及过图稳定后才开始准备。同图传送必须实际过图；传送拒绝、未解锁、超时会停止后续制作、采集与触发。
- 准备期间持续核对所在地；停止命令清除队列及旧命令，只关闭水桶发起的 Artisan 连续制作。
- 传送回归检查：dotnet run --project tests/TravelChecks -c Release。

## 本地增强

- 插件加载和角色登录时，窗口默认关闭。使用 `/水桶` 或 `/srankflag` 打开主窗口。正常过图仍保留手动打开的窗口。

- 主窗口“悬浮窗”按钮打开独立的订阅提醒。关闭后可从主窗口重新打开，也可使用 `/水桶 watch` 切换。倒计时与彩色服名分别占行，右下角调尺寸，位置可锁定。右键 S 怪详情可加减当前服的订阅。同名 S 指定服务器后，悬浮窗优先显示这些指定服。订阅管理列表可以取消单独的服务器订阅。
- 过图前打开的原生窗口在落地后恢复。订阅管理顶部固定，切换视图或搜索时回到列表顶部。
- 主列表左键点表头排序。右键点“服务器”可勾选当前大区的服务器；右键点“怪名”可勾选要显示的 S 怪。两项都立即更新本地列表，不会触发网络刷新。怪种筛选跨大区生效，兼容原有的 `hidden_hunts.json`；也可以在“已隐藏”窗口逐项或全部恢复。自动前往会跳过隐藏怪种尚未出发的任务。
- 隐藏列表不删除击杀历史、计时缓存或条件订阅。离线持久化检查：`dotnet run --project tests/VisibilityChecks -c Release`。
- 主列表勾选“开闸”只显示已进闸，达到 100% 后仍保留；取消只显示冷却中、尚未进闸的 S，并显示进闸倒计时。空列表不自动回退为全部。
- 主站 `/api/live` 第三个标记是维护标记，按维护 CD 计算并写入缓存，与公开熊站的 `Canceled` 字段分别解析。235 个豆豆柴样本与网站独立计时模块逐项对账。
- 主窗、自动前往、触发悬浮窗、设置、历史及条件订阅窗都可拖动右下角的原生纹理角标调整宽高，分别记忆尺寸。列宽和按钮重排，长文字自动缩放、换行或截断，并提供完整悬停提示；高度不足时滚动。
- 精确设置：`/水桶 size main 820 620`。窗口名支持 `main`、`auto`、`hud`、`settings`、`history`、`conditions`。
- 主窗右键 S 怪行展开详情：“目的地与操作”里的“大水晶”和当前服务器的悬浮窗订阅按钮并排显示。可悬停查看完整触发说明，也可用 `/水桶 detail 虚无探索者` 打开当前筛选内的详情。
- `/水桶 conditions` 或主窗“条件订阅”打开可选条件窗。参考主站，平时只显示怪名、倒计时和已进闸服的色签，触发方法与各服冷却放到悬停提示；搜索、全选和逐只勾选放在“订阅”面板。
- 默认订阅 13 只天气、ET 或月相 S；全部 47 只仍可在订阅管理选择。未进入条件为红色，距开始不超过 5 分钟为黄色，条件内为绿色。其他 S 显示“无固定时间窗”，不编造倒计时或行动条件已完成标记。各服 CD 与条件时间分别计算。
- 原生文字、状态色、悬停色和历史底色随游戏主题适配。有底纹的原生按钮保留白字。服名跨窗口保持同色；豆豆柴五服参考主站，其他服使用稳定且不同的颜色。

条件数据取自 2026-11-14 的[主站目录及悬浮窗](http://119.29.119.179/srank/)，保存于 `assets/hunt_conditions.json`。使用 52 个主站独立计算样本对账，并检查开始、5 分钟、结束边界、巨大鳐的跨日持续窗口、全部 S 的目录覆盖与服务器配色。框架用法记录见 [KamiToolKit.md](docs/KamiToolKit.md)。

## 本地开发

需要 .NET 10 SDK 和 API 15 的 Dalamud。当前工程默认读取 `%APPDATA%\XIVLauncherCN\addon\Hooks\dev`，可通过 `DALAMUD_HOME` 环境变量或脚本参数指定其他 SDK 目录。

在 PowerShell 中运行：

```powershell
.\build-local.ps1
# 自定义 Dalamud SDK：
.\build-local.ps1 -DalamudLibPath 'C:\path\to\Dalamud'
```

脚本将编译文件部署到 `artifacts/dev/SrankFlag/`。已注册的开发插件路径为该目录下的 `SrankFlag.dll`；在当前游戏中已开启自动重载，重新运行脚本后 Dalamud 会自动加载更新。重建脚本先复制依赖，最后复制主 DLL；现有设置和运行缓存保留，`srank_data.json` 仅首次部署时初始化。

游戏内使用 `/水桶` 或 `/srankflag` 开关主窗口；`/水桶 settings` 打开设置。插件名称为“魔法水桶”，本地加载时在开发插件列表管理。

运行 `./build-release.ps1` 生成 `artifacts/release/v1.2.14.6/SrankFlag.zip` 和 SHA256 校验文件。发布脚本只打包明确列出的程序集、初始狩猎数据和许可证，不包含本地偏好、缓存或订阅设置。正式发布说明见 [release-notes.zh-CN.md](release-notes.zh-CN.md)。
